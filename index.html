Записи всех разделов могут храниться в одном файле GitHub, доступном на любом устройстве. Читать общую базу можно без авторизации. Для сохранения нужен собственный GitHub-токен администратора с правом записи в этот репозиторий. Токен остаётся только в памяти открытой вкладки, не добавляется в код и не передаётся другим пользователям.

Для первого подключения: создай fine-grained token → владелец renegatjo-commits → только репозиторий safespace-admin-editor → Repository permissions: Contents — Read and write. Другим администраторам нужен собственный доступ на запись: у GitHub есть ограничения для fine-grained токенов внешних соавторов. Никому не передавай свой токен. Для команды без GitHub-аккаунтов лучше подключить отдельную базу с входом по почте. Перед переносом с другого устройства скачай резервную JSON-копию.

Перенос и восстановление

С общей базой GitHub данные доступны на любом устройстве: новая запись становится общей после успешной публикации. JSON остаётся резервной копией и способом безопасного переноса старых локальных изменений. TXT нужен для форума.
